# Triage Labels

This repo does not currently use an active triage label workflow. It is a solo direct-to-main project with no expected issues or pull requests.

If the user later decides to use an issue tracker, the default mapping below is available as a starting point.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Do not create or apply labels unless the user explicitly asks to start using an issue tracker.
